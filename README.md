# Docket

A Paseo plugin that lets an agent show the user a *surface*: a display wrapped around a typed set of questions, held by the plugin server and answerable from the chat, a side panel or one inbox across every agent. Answers reach the agent later as a structured response.

Status: Pre-alpha: nothing is built yet. Design and research live in the planning repository (`projects/docket/` in toolkit-research).

- Plugin id: `docket`
- Agent tools: `docket_show`, `docket_close`, `docket_get`, `docket_reference`
- Requires Paseo 0.16.0-beta.2 or later (provisional; see OVERVIEW.md)
