The hub and the components. No `class` (Hermes). Components map a view model from `shared/` to elements and hold no state except scroll and what is open.

In Stage 1, Markdown image syntax renders as alt text.

Flowcharts with dotted or thick edges or self-loops display their Mermaid source as code.
Closed and replaced surfaces show saved unsent item comments. Users can send drafts against the original surface while its details are retained. After compaction, users can still read, copy, or clear those drafts from the surface card.
